# Marks Analyzer

A simple Python script that takes 5 marks as input and calculates the total and the largest mark.

## What it does

- Takes 5 numbers (marks) as input from the user
- Calculates the total of all marks
- Finds the largest mark
- Prints the list, total, and largest mark

## How to run

```bash
python marks_analyzer.py
```

You'll be prompted to enter 5 marks one by one.

## Example

```
Enter your marks: 80
Enter your marks: 90
Enter your marks: 75
Enter your marks: 60
Enter your marks: 100
List: [80, 90, 75, 60, 100]
Total: 405
Largest number: 100
```
